# Dashboard

The dashboard is the main monitoring view: each printer is shown as a card with live video, inference status, and quick controls.

## Overview

From here you can:

- View printer status (idle/printing/etc.)
- Watch the live feed
- See inference results (normal/defect) and detection rate
- Control the printer (if a control component is configured)
- Toggle inference on/off
- Enable/disable notifications per printer

## Usage

1. Open **Dashboard** to see all configured printers.
2. Use the control buttons (start/pause/stop) when a printer has a control component.
3. Click **Stop Inference / Start Inference** to pause/resume detection for the current session.
4. Click the **timeline** chevron to view recent inference history.
5. Use the **bell** icon to toggle notifications for that printer (requires browser permission and a device subscription).
